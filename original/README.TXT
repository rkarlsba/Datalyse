Datalyse for Windows

Licence: 
Datalyse is freeware



Installation:
Copy all the files in the zip-file to a directory on your harddisc.
No special drivers are necessary, you only have to install datalyse
in you windows-environment.

There is an online help for all functions at www.datalyse.dk. It is a good idea, to read
some of it. It gives an idea of the programs capabilities.

Files:
	Datalyse.exe; the program
	Datalyse.ini; ini file for datalyse.
	Syredata.ini; editable file with data on acids.
	Basedata.ini; editable file with data on bases.
	vernier.ini;  editable file with information on vernier-probes.

	*.dat; data files for datalyse, these are dispensable.
	*.lyd; data files for datalyse, these are dispensable.
	*.txt; data files for datalyse, these are dispensable.


	Readme.txt; this file
 

Uninstallation:
Delete the installed files.

If you find any errors in the program or have any ideas for improvement, 
let me know.
