# Device support

Generated by `scripts/make_device_doc.py`. Do not edit by hand.

**`driver`** is the key in `datalogger/drivers/catalog.py`.
**`provenance`** says how much of the protocol is actually known:

| provenance | meaning |
|---|---|
| **exact** | the vendor help documents the whole measurement exchange; the parser is a transcription |
| identity exact | the identify command and its expected answer were recovered from `Datalyse.exe`; the measurement query comes from the instrument's own manual, not from Datalyse |
| settings only | baud/parity/stop/data and the identification strings are known, the response layout is not — `generic` reads a line and extracts the numbers |
| n/a | the number is reserved and unused in `Datalyse.ini` |
